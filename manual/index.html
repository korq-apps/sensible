Sensible User Manual

This manual is permanently installed on your system at /usr/share/sensible/manual/ and is always accessible offline from the application menu (Sensible Manual) or terminal by running sensible-manual.

1. Welcome to Sensible

Sensible is an opinionated remix of Debian Testing (Forky) for 64-bit x86 (amd64) UEFI systems. The installed operating system is pure Debian: the UEFI boot entry is Debian, system packages come from Debian repositories, and Debian system administration standards apply throughout.

Sensible packages the entire system closure into an offline installer ISO, ensuring installations are predictable, reproducible, and do not depend on mirror availability during disk setup.

2. Your First Five Minutes

Follow these quick orientation steps right after logging in:

  1. Connect to Network: Use the network menu in the top-right status area (GNOME) or bottom-right system tray (KDE) to connect to Wi-Fi or Ethernet.
  2. Update Package Lists & System: Open a terminal and run standard Debian updates: 
    sudo apt update && sudo apt full-upgrade
  3. Reboot on Core Updates: If a new kernel, systemd, or graphics driver is installed during updates, restart your system to engage the new components.
  4. Check Device Firmware: If your vendor provides updates through the Linux Vendor Firmware Service (LVFS), check with fwupd: 
    sudo fwupdmgr refresh
sudo fwupdmgr get-updates
sudo fwupdmgr update
  5. Explore Applications: Open Software (GNOME) or Discover (KDE) to browse and manage installed tools and Flatpaks.

3. Desktop Basics & Shortcuts

GNOME Edition

The GNOME edition is configured for a focused, fluid workflow:

  • Super (Windows key): Tap to open the Activities Overview, search applications, and switch dynamic workspaces.
  • Clipboard Shortcuts (keyd): GNOME includes a system-level key remapping service (keyd) mapped for Mac-style clipboard muscle memory:
    Shortcut Action Terminal Behavior
    Super + C Copy selection Sends Ctrl+Insert (safe: does not send SIGINT interrupt signal)
    Super + V Paste clipboard Sends Shift+Insert (safe paste in GUI and terminal)
    Super + X Cut selection Sends Ctrl+X
    Terminal Protection
    In traditional Linux terminals, Ctrl+C interrupts running processes. Super+C allows clean copying without terminating jobs.
  • Workspaces: Switch between virtual workspaces with Super + Page Up / Page Down or three-finger vertical touchpad gestures.

KDE Plasma Edition

The KDE edition follows traditional desktop conventions:

  • Standard bottom taskbar, application launcher menu, and system tray.
  • Window switching via Alt + Tab.
  • Standard Linux shortcut bindings (keyd is not enabled on KDE).

Screen Locking & Session Defaults

  • Idle Timeout: The screen locks automatically after 5 minutes of inactivity on both GNOME and KDE.
  • Resume Lock: KDE explicitly locks on resume; GNOME follows its desktop defaults.
  • Automatic Login: If selected during an encrypted installation, automatic desktop login engages after unlocking the LUKS2 disk at boot. Unencrypted installs always require password login.

4. Installing Software

Sensible provides standard package management tools for Debian and Flatpak:

System Packages & CLI Tools (APT)

Use apt for system software, drivers, command-line utilities, and developer runtimes:

# Search for packages
apt search <name>

# Install packages
sudo apt install <package-name>

Graphical & Desktop Applications (Flatpak & Flathub)

Flatpak integration is included in the base installation. Because the install is performed offline, Flathub remote configuration is verified on first network connection.

To verify or add the Flathub repository:

# Check existing Flatpak remotes
flatpak remotes

# Add Flathub if not already present
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

Once Flathub is added, browse and install desktop applications (e.g., Slack, Spotify, Discord, VS Code) directly from GNOME Software or KDE Discover.

6. Storage & Security

Disk Partitioning Model

Sensible configures a dedicated GPT layout on the target drive:

Partition Size Filesystem Mountpoint Encrypted (LUKS)
Partition 1 1024 MiB FAT32 (ESP) /boot/efi No (UEFI specification)
Partition 2 1024 MiB Ext4 /boot No (Unencrypted kernel & initramfs)
Partition 3 Remainder Btrfs or Ext4 / (root) Optional LUKS2

Root Filesystems

  • Btrfs: Structured with dedicated subvolumes:
    • @ mounted at /
    • @home mounted at /home
    • @snapshots mounted at /.snapshots
    • @var_log mounted at /var/log
    • @swap mounted at /swap (uncompressed swapfile host)
  • Ext4: Traditional single root filesystem with fast_commit enabled.

Swapfile & Hibernation

Swap is configured as a dedicated swapfile inside root (matching RAM capacity). When LUKS is enabled, the swapfile is located inside the encrypted container and is protected at rest.

Secure Boot & Hibernation
Under UEFI Secure Boot lockdown, the Linux kernel disables unverified hibernation resumes to protect kernel integrity. Hibernation works when Secure Boot is disabled.

Unencrypted /boot & Secure Boot Chain

/boot is left unencrypted to enable smooth graphical boot unlock via Plymouth and avoid fragile GRUB cryptodisk drivers. The boot chain is protected by UEFI Secure Boot using Debian's Microsoft-signed shim and Debian-signed GRUB binaries.

7. Hardware & Peripherals

  • Kernel & Firmware: Modern Debian Testing kernel with complete non-free-firmware package set (Intel, AMD, Realtek, Broadcom, MediaTek, SOF audio).
  • Audio & Bluetooth: PipeWire and WirePlumber manage audio routing and Bluetooth profiles.
  • Power Management: power-profiles-daemon provides integrated power modes (Power Saver, Balanced, Performance) in desktop settings.
  • Printing & Scanning: CUPS, ipp-usb, and sane-airscan provide driverless IPP/eSCL printing and scanning support.
NVIDIA Hardware & Secure Boot
If your system uses a proprietary NVIDIA GPU, the kernel module requires signing to load under Secure Boot. If graphics fall back to software rendering, either enroll a Machine Owner Key (MOK) or disable Secure Boot in UEFI firmware settings.

8. Backups & Snapshots

Disk encryption protects data when the computer is powered off or stolen, but it is not a backup. A hardware failure, filesystem corruption, or accidental deletion can still cause permanent data loss.

  • Btrfs Readiness: The Btrfs layout includes a dedicated @snapshots subvolume and isolates @swap outside snapshots. You can install tools like Snapper or Timeshift from APT: 
    sudo apt install snapper
  • External Backups: Maintain regular backups of /home on external storage or remote destinations using tools like BorgBackup, Restic, or Pika Backup (available on Flathub).

9. Troubleshooting & Diagnostics

Installation Logs

The installer records detailed execution steps in /var/log/sensible-install.log. To inspect the install history:

sudo less /var/log/sensible-install.log

Common Diagnostic Commands

# Check storage devices and mountpoints
lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS

# Check network interfaces
ip link

# View system journal for the current boot
journalctl -b --no-pager

# Check system hardware and services
systemctl status
Log Sanitization Reminder
When sharing diagnostic outputs online, always redact usernames, Wi-Fi networks, MAC addresses, and private file names. Never post passwords or encryption passphrases.

  • Biometric Authentication: Integrated fingerprint login and BioPass face recognition enrollment.
  • Firewall Presets: Pre-configured ufw policies and KDE Connect firewall discovery rules.
  • Shell Enhancements: Pre-configured Oh My Bash themes and expanded Git global defaults.
