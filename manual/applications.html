Everyday applications

What each app adds, and something useful to try first. Open graphical apps by searching for their names in the desktop application menu.

Why this selection?

The baseline covers browsing, documents, mail, passwords, media and files without an immediate trip to an app store. Most tools use Debian's update path; LocalSend is a pinned upstream package with a separate update policy below. Native GNOME or KDE utilities handle smaller everyday tasks; the shared apps give both editions a familiar core.

These are reasons to provide the tools, not a claim that each is the only good choice. Use the ones that fit your workflow. Installation and this guide work offline; websites, mail delivery, account setup, software downloads and some editor plugins require a connection.

This chapter describes the image configuration, not the entire desktop wishlist. Photo tools, LocalSend and phone-integration packages are included. Curated GNOME extension activation, additional extensions, widgets and themes remain a later step.

Browsers & communication · both editions

LocalSend

Why included: nearby file sharing across desktop and phone platforms without a cloud account. It needs a local network, but not internet access for a transfer.

Try: open LocalSend on both devices on the same trusted network. Select a file and recipient in Send, then accept it on the receiving device. Check the destination folder and leave automatic acceptance off. The other device needs its own LocalSend installation.

If discovery fails, check that both apps are open and the network permits devices to communicate; guest Wi-Fi may isolate clients. See the sharing firewall notes before changing security settings. Upstream setup reference.

Updates: this image includes the verified upstream 1.18.2 package, not a Debian repository package. Ordinary Debian updates do not supply new LocalSend releases. Sensible refreshes the pin for future images; on an existing installation, obtain a reviewed newer amd64 Debian package from the official releases, verify its published SHA-256 and install it with APT. No updater or extra repository is enabled here.

Firefox ESR

Why included: a general-purpose browser with Mozilla's extended-support release cadence. It provides an everyday browsing option alongside the Chromium engine.

Start here: press Ctrl + L to enter an address or search, and Ctrl + D to bookmark the page. Use the bookmark menu for regularly used sites. Local HTML files, including this manual, can be read offline.

Chromium

Why included: a second browser engine for sites or development work that behave differently in Firefox. It is not a requirement to use two browsers.

Start here: try a troublesome site in Chromium before changing system settings. Keep bookmarks and sign-ins separate unless you deliberately import them; installing Chromium does not set up Google Chrome account synchronization.

Thunderbird

Why included: desktop email that can bring several accounts into one interface and retain downloaded messages for offline reading.

Start here: add an existing email account and follow your provider's sign-in instructions. Check offline/synchronization settings before travelling: an account being visible does not mean every message body has been downloaded. Sending and receiving need a connection.

Documents & passwords · both editions

LibreOffice Writer

Why included: letters, reports and other formatted documents without a cloud account.

Start here: create a document, apply heading styles instead of manually enlarging headings, and save an editable .odt copy. Export a PDF when the recipient only needs to read or print it. Review layout after exchanging Microsoft Office files.

LibreOffice Calc

Why included: budgets, lists, calculations and small data tables.

Start here: enter numbers in cells A1 through A5, then enter =SUM(A1:A5) in A6. Save as .ods to retain formulas and formatting; CSV is a plain table format, not a full workbook.

LibreOffice Impress

Why included: preparing and presenting slide decks offline.

Start here: choose a slide layout, add a title and a few points, then start the slideshow with F5. Keep the editable .odp file and export a PDF handout. Test imported presentations and external displays before presenting.

KeePassXC

Why included: a local encrypted password database that does not require a hosted service.

Start here: create a database, choose a strong master passphrase and add one entry using the password generator. Back up the .kdbx file and keep the passphrase recoverable by you: losing it can mean losing access to the database. Browser integration and synchronization need separate setup; neither is configured automatically.

Media & editing · both editions

VLC

Why included: one player for many local audio and video formats, with subtitle support.

Start here: drag a video into the window, press Space to pause, and choose a subtitle file from the Subtitle menu if needed. Local media works offline; streaming addresses need a network connection.

Neovim & the LazyVim starter

Why included: a keyboard-driven editor for code and configuration, also usable in a terminal without a desktop.

Start here: run nvim notes.txt. Press i to type, then Esc, type :wq and press Enter to save and quit. :q! quits without saving your changes.

The supplied LazyVim starter needs internet for its initial plugin downloads. For a basic editor session without loading that configuration, run nvim --clean notes.txt. Run nvim --clean and enter :Tutor for the built-in lesson.

GNOME utilities · GNOME image only

Shotwell

Why included: organizing a photo library rather than just opening individual images. Try: import a small folder first, inspect its import/copy settings, then tag and rate a few pictures. Keep a separate backup of originals; a catalog is not a backup.

Extension Manager

Why included: one place to inspect, enable and disable Shell extensions. Try: use Installed to manage the packaged GSConnect and AppIndicator extensions. Browsing or downloading other extensions requires internet and compatibility with your Shell version. This slice does not automatically enable a curated extension set.

GNOME Tweaks

Why included: additional font and appearance controls alongside Settings. Try: change one font setting at a time and note its original value. Installing Tweaks does not install the planned theme collection.

GSConnect

Why included: KDE Connect protocol integration in GNOME without running Plasma's competing implementation. Try: enable GSConnect in Extension Manager, install KDE Connect on your phone, and request and accept pairing on the same trusted network. Review individual plugins and phone permissions; enable only the notification, file-sharing or remote-control features you want. No device is pre-paired and browser extensions are not installed for you.

AppIndicator support

Why included: tray/status icons for apps that use them, including LocalSend. Enable it in Extension Manager if you want those indicators. This supplies compatibility, not a second application launcher or a new theme.

GSConnect support packages: SSHFS supports remote file access; the Nautilus Python bridge supports file-manager integration. The introspection libraries and Folks address-book backend provide accessibility, contacts/accounts, sounds, text and power interfaces. These are dependencies, not extra apps you need to launch; they neither enroll accounts nor grant phone permissions automatically.

File Roller (Archive Manager)

Why included: browsing and unpacking archives without memorizing commands. Try: open a ZIP, inspect its contents, then extract into a new folder so existing files are not accidentally overwritten. Creating an archive is also available through the file manager's compression action.

Amberol

Why included: a small, focused local music player alongside VLC's broader media support. Try: add a music folder and use the queue to choose what plays next. It does not provide a streaming-service account or catalog.

Document Scanner (Simple Scan)

Why included: a straightforward route from paper to a PDF or image. Try: select a supported scanner, scan a page, crop or rotate it, and save. Scanning creates an image; searchable text requires a separate OCR workflow.

KDE utilities · KDE image only

digiKam

Why included: a full photo catalog with albums, tags and search; Gwenview stays available for quick viewing. Try: choose a small local photo collection in the first-run wizard, review database locations, then tag a few images. Back up both original photos and the catalog. Optional recognition/model downloads are not preseeded; basic local organization does not need them. Upstream overview.

KDE Connect

Why included: phone integration using Plasma's native interface. Try: open KDE Connect settings, install the companion app on your phone, then request and accept pairing on the same trusted network. Review plugins and phone permissions before enabling notification sharing or remote input. Pairing is never preconfigured; use LocalSend for a simple one-off file transfer without persistent phone integration.

Plasma System Monitor

Why included: a graphical view of CPU, memory and running processes. Try: watch resource use while opening an app, or sort the process list by memory. Ending a process can lose unsaved work; observation is the safe first step. Custom sensor widgets and panel layouts are a later profile change.

Okular

Why included: a document/PDF reader with annotation tools. Try: search a PDF with Ctrl + F, add a highlight using the annotation tools, and save a copy. Reopen that copy to check annotations are retained before sharing it.

Ark

Why included: Plasma's native archive manager. Try: open an archive to inspect its file list, then extract into a new directory. Do not run unfamiliar programs just because they arrived inside an archive.

Gwenview

Why included: quick image viewing and simple adjustments without launching a photo-library manager. Try: open a photo folder, step through images and rotate a sideways photo. Save a copy when preserving the original matters.

Kate

Why included: a graphical text/code editor for people who prefer tabs and menus to Neovim's modes. Try: open two text files in tabs, search with Ctrl + F, and save with Ctrl + S. Use Writer, not Kate, for rich-text documents.

KCalc

Why included: fast calculations without creating a spreadsheet. Try: enter a calculation such as 125 * 1.2; use the scientific mode for advanced functions. Use Calc when you need to retain a table of calculations.

Spectacle

Why included: screenshots of a region, window or screen. Try: launch Spectacle, choose a rectangular region, capture it and save the image or copy it to the clipboard. Check for passwords and private notifications before sharing. This baseline does not add the planned OCR/Lens companion.

Elisa

Why included: a music-library player integrated with Plasma. Try: point its music-location settings at your local collection, browse albums and create a playlist. VLC remains useful for video and one-off media files.

Skanlite

Why included: a lightweight graphical scanning tool. Try: select a supported scanner, preview the page, select the scan area and save the resulting image. OCR and document organization are separate tasks.

Software, archives & fonts

Sharing and the firewall

Both editions keep UFW enabled with incoming traffic denied by default. Exceptions allow TCP/UDP 53317 for LocalSend and TCP/UDP 1714–1764 for GSConnect/KDE Connect. The generated rules cover IPv4 and IPv6 with Debian's default IPv6-enabled UFW configuration.

These exceptions apply to all interfaces and source addresses, not only private or trusted networks. Use sharing on trusted networks, reject unexpected requests, and stop sharing apps or disable their plugins on public Wi-Fi. Do not forward these ports on your router. Inspect the actual active rules with sudo ufw status verbose; disabling the firewall is not a discovery fix.

Desktop integration dependencies: GTK, Secret Service and Ayatana libraries support LocalSend's interface and tray integration; EGL/OpenGL ES and Mesa provide graphics rendering. XDG user directories and desktop portals supply standard folder locations and native file selection, with GNOME/GTK or KDE backends selected per edition. These are supporting components, not programs to learn or evidence that an application is sandboxed.

Flatpak & desktop stores

Why included: another application distribution route, integrated with GNOME Software or KDE Discover. It supplements APT; it does not replace Debian's system updates.

Try: flatpak list lists installed Flatpak apps/runtimes and flatpak remotes shows configured sources. The base ISO does not configure Flathub or install Flatpak apps. Follow repository setup when online; flatpak update then checks for and offers Flatpak updates. Review an app's permissions rather than assuming every sandbox provides the same access limits. Upstream reference.

7-Zip, unzip & zip

Why included: compatible archive handling for downloaded files and sharing bundles, also supporting desktop archive managers. Compression alone is not encryption or a backup policy.

Try: inspect before extracting; replace the example filenames with your own. The extraction commands below create files, so use a new destination.

# List a ZIP; then extract into a new folder
unzip -l photos.zip
unzip photos.zip -d unpacked-photos

# Create a ZIP containing a folder (does not delete the source)
zip -r notes.zip notes/

# Debian's 7zip package provides 7zz
7zz l bundle.7z
7zz x bundle.7z -ounpacked-bundle

Debian 7zz command reference.

Noto, emoji, Liberation & Powerline fonts

Why included: Noto broadens language/script coverage, Noto Color Emoji supplies emoji glyphs, and Liberation helps documents using common office-font metrics retain familiar layout.

Try: select a Noto or Liberation family in Writer's font selector and inspect a document containing your language's characters. Font substitution can still change layout; check the exported PDF.

The shell uses Oh My Bash's two-line Powerline prompt by default. The Debian Powerline font supplies compatible separator symbols, while the image also stages JetBrainsMono Nerd Font for terminal icons. If prompt symbols appear as boxes, choose JetBrainsMono Nerd Font in the terminal profile and reopen the terminal. Fonts are resources, not separate apps to launch.
